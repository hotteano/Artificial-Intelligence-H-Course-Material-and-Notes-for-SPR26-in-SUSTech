Simulated Annealing
• Generate an initial x(0)
• Set the initial temperature T(0);
• Do while (halt condition is not satisfied)
   Get current temperature T(i);
   Generate solution x’ based on x(i)
   Calculate f(x’) and Df = f(x(i)) - f(x’)
   If Df ＜0 (for maximization) ，then x(i+1)= x’
   Otherwise, p = exp(- Df /T(i));
        If c = random[0,1] < p, x(i+1)= x’;
        Otherwise x(i+1)= x(i);
   i=i+1
   Update T(i);
• End Do

Population-based Search: A Concrete Example
• Set i=0; Population_size = N
• Generate N initial solutions, X(0);
• Do while (halt condition is not satisfied)
   Evaluate the quality of the solutions in X(i); (% calculate f(x) for each solution)
   Use the top k solutions in X(i) to build a Gaussian Distribution Pi
   Sample another N according to Pi , as X(i+1)
   i=i+1
• End Do

The example could be viewed as searching for a good probability distribution
(parameters of the Probability Density Function), from which good solutions could be
sampled.

 Extended Information – Constrained Optimization
  Most realistic problems are subject to constraints
  • f(x): the objective function
  • gi(x): the inequality constraints
  • hj(x): the equality constraints
  But they could be transformed into unconstrained problems.


minimize f (x)
subject to: gi (x) ≤ 0, i = 1...m
             h j (x) = 0, j = 1... p

Extended Information – Multi-Objective Optimization
• Multi-objective optimization problem:
                       minimize F(X) = ( f1 (x),..., fm (x))
• The objective functions may be conflicting or incommensurable.
• Instead of a single optimal solution, a set of the best trade-off solutions (Pareto
  optimal solutions) are sought.




                                                                                        33
Extended Information – Multi-Objective Optimization
Multi-objective optimization itself involves multiple criteria.
Intuitively, we want a set of solutions that is good in terms of:
• Convergence (to the Pareto front)
• Spread (along the Pareto front)


You can also transform them into single-objective problems, or
Use population-based search
• If interested, check the Non-dominated Sorting Genetic Algorithm II paper published in 2002 to start.
• Or consult with Prof. Hisao Ishibuchi.

Remarks
• All search methods talked in this lecture are general-purpose search frameworks (like A*),
  rather than search algorithms. Each search frameworks encompasses many concrete
  instantiations (algorithms).

• When addressing a specific problem
    • You can use the off-the-shelf version, or

    • heuristics derived from domain knowledge could be incorporated in forms of search operators
      to obtain better performance.
